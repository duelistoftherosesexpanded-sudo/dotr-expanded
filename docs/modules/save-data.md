# SzData: save data, decks, ranks

46 functions, 12,304 bytes, all byte-matching. Names are the Japanese build's symbols where it has one ([topics/jp-build-symbols.md](../topics/jp-build-symbols.md)); `func_<address>` where it has none. Descriptions are readings of the C; field and parameter meanings are interpretations unless [GAME_DATA.md](../GAME_DATA.md) records evidence. The module's place in the program: [ARCHITECTURE.md](../ARCHITECTURE.md).

- **`SzData_Initialize`** `0x214290`, 828 bytes: Clears both side objects at `0x32f790` (0x1ff40 bytes) and then resets each one as SzData_ClearData does, with the entry reset inline: every card entry emptied with kind 3, the five recent-card halfwords at `+0xfd88` and the three deck lists set to 999, the special counters and treasure flags cleared, the 5 x 7 x 7 bytes at `+0xfea3` set to 7, and the option bits of `+0xff9c` set. Unlike SzData_ClearData it leaves the key word `+0xff98` at zero from the clear and sets the map-edit bit (bit 5).
- **`SzData_SetRoseFlag`** `0x2145d0`, 12 bytes: Stores the low byte of the argument in `gSzData_bRoseFlag` (`0x34f6d0`), the side value that selects the first of the two side objects.
- **`SzData_GetData`** `0x2145e0`, 64 bytes: Returns the first side object (`0x32f790`) when the argument equals `gSzData_bRoseFlag`, otherwise the second (`0x32f790 + 0xffa0`). Every side-indexed routine below selects its object the same way.
- **`SzData_ClearData`** `0x214620`, 748 bytes: Resets one side object: clears all nine card entries of each of the 854 card records through SzData_ClearCardInfo along with each record's rank (bits 0-13), experience halfword `+0x4a` and bits 14 / 15; sets the five recent-card halfwords at `+0xfd88` and each deck list's forty cards and leader to 999 and its cost to 0; clears the sixteen special counters at `+0xfe90` and the treasure flag bytes from `+0xfea0`; sets the 5 x 7 x 7 bytes at `+0xfea3` to 7; clears the key word `+0xff98`; and sets the deck selection to 0, option bits 2-4 to 1 and the map-edit bit to 0.
- **`SzData_GetConstDeck`** `0x214910`, 120 bytes: Returns the card id (low 12 bits) at `deck` 0..50, `slot` 0..40 of the constant deck table at `0x2d0970`, or -1 when either index is out of range.
- **`SzData_SetupFromConstDeck`** `0x214990`, 540 bytes: For a constant deck 0..50: clears the side, sets the key word `+0xff98` (`deckIndex` + 0x40000000 for decks 17 and up; for decks 0..16 a non-zero 31-bit value from the summed 13-bit fields of a list in the table at `0x2d49d4` plus a random draw), adds the deck's 41 cards to the bag, resets the recent-card list, sets the leader's rank from the top four bits of its entry, pushes the leader and the forty cards into deck list 0, and frees three text groups through SzText_Free. Other deck numbers do nothing.
- **`SzData_SetOption`** `0x214bb0`, 324 bytes: Stores a flag in option bit 2, 3 or 4 of byte `+0xff9c` (`which` 0, 1 or 2) and returns 1; for bit 4 it also passes the stored bit to SzSound_SetOutput. Any other `which` returns 0. The side is not range-checked.
- **`SzData_GetOption`** `0x214d00`, 200 bytes: Returns option bit 2, 3 or 4 of byte `+0xff9c` as 0 or 1 for `which` 0, 1 or 2, or -1 for any other `which`.
- **`SzData_CheckBag`** `0x214dd0`, 292 bytes: Returns the first non-empty card entry of a card's record whose kind (bits 30-31 of the second word) equals `kind` and whose bit 31 of the first word matches `flag == 1`, or null when none matches or the side (0..1) or card id (0..853) is out of range. Like the other per-card routines it maps id 671 to 999, which then fails the range test.
- **`SzData_GetCardInfo`** `0x214f00`, 204 bytes: Returns the address of entry `n` (0..8) of a card's record, or null when the side, entry index or card id is out of range.
- **`SzData_ClearCardInfo`** `0x214fd0`, 136 bytes: Empties a card entry (both value fields cleared, kind set to 3, bit 31 cleared) and returns 1; a null entry returns 0.
- **`SzData_CheckDup`** `0x215060`, 356 bytes: Returns 1 when a non-empty entry of the card's record holds `uniqueId` in its 30-bit serial field, else 0. A zero `key` is replaced by the side's key word `+0xff98`; -1 is returned when that is zero too or the side or card id is out of range. The key is not otherwise used.
- **`SzData_CheckDeck`** `0x2151d0`, 168 bytes: Returns the position (0..39) of the first occurrence of `cardNo` in deck list `deckNo`, or -1 when absent or the side is out of range.
- **`SzData_PushDeckLeader`** `0x215280`, 328 bytes: Makes a card the leader of deck list `deckNo`: requires the leader halfword `+0x50` to be vacant (999) and a free (kind 3, flag 0) entry for the card, stores the id there, sets the entry's kind to `deckNo` and its bit 31, and returns 1; otherwise 0.
- **`SzData_PullDeckLeader`** `0x2153d0`, 260 bytes: Removes the leader of deck list `deckNo`: finds the leader's entry of kind `deckNo` with bit 31 set, sets the leader halfword back to 999, returns the entry to kind 3 with bit 31 cleared and returns 1; 0 when there is no leader or entry.
- **`SzData_PushDeck`** `0x2154e0`, 648 bytes: Adds a card to deck list `deckNo`. Returns 0 for an out-of-range side or id, when the list already holds three copies, when it has no vacant (999) position, or when there is no free (kind 3, flag 0) entry or constant card info (SzDuel_GetCardConstInfo); otherwise adds byte 3 of the card's constant info (its deck cost) to the list total `+0x52`, stores the id in the first vacant position, sets the entry's kind to `deckNo` and returns 1.
- **`SzData_PullDeck`** `0x215770`, 320 bytes: Removes the card at position `deckSlot` (0..39) of deck list `deckNo`: finds its entry of kind `deckNo` (flag 0), subtracts its deck cost from the list total `+0x52`, sets the position to 999, returns the entry to kind 3 and returns 1; 0 on any failure.
- **`SzData_GetCurrentDeck`** `0x2158b0`, 108 bytes: Returns the two-bit deck selection (bits 0-1 of byte `+0xff9c`), or -1 for an out-of-range side.
- **`SzData_SetCurrentDeck`** `0x215920`, 168 bytes: Stores a deck selection 0..2 in bits 0-1 of byte `+0xff9c` and returns 1; 0 when the side or value is out of range.
- **`SzData_GetLeader`** `0x2159d0`, 132 bytes: Returns the leader halfword `+0x50` of deck list `deckNo` (999 when vacant), or -1 for an out-of-range side.
- **`SzData_GetCardNo`** `0x215a60`, 172 bytes: Returns the card id at position `cardSlot` (0..39) of deck list `deckNo` (999 when vacant), or -1 when the side or position is out of range.
- **`SzData_CalcExp`** `0x215b10`, 300 bytes: Applies an operation to a card record's experience halfword `+0x4a`: add, subtract, multiply, divide or set (`op` 0..4) with `expChange`, clamping the result to 0..65535, and returns 1; 0 for an out-of-range side or id or an unknown operation.
- **`SzData_CalcDeckCost`** `0x215c40`, 232 bytes: Recomputes deck list `deckNo`'s total `+0x52` as the sum of the deck costs (byte 3 of SzDuel_GetCardConstInfo) of its forty positions and returns it; -1 for an out-of-range side.
- **`SzData_GetRank`** `0x215d30`, 172 bytes: Returns a card record's rank (bits 0-13 of `+0x48`) for card ids 0..682, or -1 when the side or id is out of range.
- **`SzData_SetRank`** `0x215de0`, 280 bytes: Recomputes a card's rank (ids 0..682) as the highest index 0..12 whose threshold in `gSzData_awExpTable` does not exceed the experience `+0x4a`, keeping it at least 1 when the stored rank was non-zero, stores it and returns it; -1 when out of range.
- **`SzData_GetDeckCost`** `0x215f00`, 132 bytes: Returns deck list `k`'s stored cost total `+0x52`, or -1 for an out-of-range side.
- **`SzData_GetDeckCount`** `0x215f90`, 168 bytes: Returns how many of deck list `deckNo`'s forty positions hold a card (are not 999), or -1 for an out-of-range side.
- **`SzData_AddBag`** `0x216040`, 564 bytes: Adds a copy of a card to the bag: in the first empty entry of its record it stores a random 30-bit serial (from the random-number routine `func_0019a5c8`, redrawn while SzData_CheckDup finds it) and the key (the side's key word `+0xff98` when `key` is 0), sets the record's look flag (bit 14), moves the card to the front of the recent list through SzData_PushBagNew and returns 1. Returns 0 when the key is zero, the side or id is out of range or all nine entries are in use.
- **`SzData_AddBag2`** `0x216280`, 520 bytes: As SzData_AddBag, but with the serial `value` given by the caller; returns 0 when SzData_CheckDup already finds that serial for the card.
- **`SzData_DelBag`** `0x216490`, 240 bytes: Empties the first free (kind 3, flag 0) entry of a card's record, removing one copy from the bag, and returns 1; 0 when there is none or the side or id is out of range. The entry clear is SzData_ClearCardInfo inlined.
- **`SzData_RollSpecial`** `0x216580`, 324 bytes: Finds the row of the sixteen-row special-card table `aSpecialCard` whose SzDuel_Xax2New(row id) equals the card id and advances the side's counter for that row at `+0xfe90`, wrapping modulo the row's alternative count plus one; returns 1 when a row matched, else 0.
- **`SzData_ExchSpecial`** `0x2166d0`, 304 bytes: Returns the alternative card id that the side's counter selects for the matching `aSpecialCard` row (the counter minus one indexes the row's alternatives), or the id unchanged when the counter is zero, no row matches or the side or id is out of range.
- **`SzData_PushBagNew`** `0x216800`, 280 bytes: Moves a card id to the front of the side's five recent-card halfwords at `+0xfd88`, shifting the earlier ones down (dropping the last when the id was not present), and returns 1; 0 for an out-of-range side or id.
- **`SzData_IsBagNew`** `0x216920`, 200 bytes: Returns 1 when a card id is among the side's five recent-card halfwords, else 0.
- **`SzData_GetBagCountAll`** `0x2169f0`, 208 bytes: Counts the non-empty kind-3 entries (copies not in any deck list) over all 854 card records of a side; -1 for an out-of-range side.
- **`SzData_GetBagCount`** `0x216ac0`, 256 bytes: Counts the non-empty entries of one card's record whose kind equals `kind`, or of any kind when `kind` is negative; -1 for an out-of-range side or id.
- **`SzData_GetLookFlag`** `0x216bc0`, 168 bytes: Returns a card record's bit 14 (set when a copy is added to the bag) as 0 or 1; 0 for an out-of-range side or id. Unlike its neighbours it does not map id 671.
- **`SzData_SetLookFlag`** `0x216c70`, 188 bytes: Stores a flag in a card record's bit 14 and returns 1; 0 for an out-of-range side or id (id 671 is not mapped).
- **`SzData_GetPassFlag`** `0x216d30`, 184 bytes: Returns a card record's bit 15 as 0 or 1; 0 for an out-of-range side or id.
- **`SzData_SetPassFlag`** `0x216df0`, 204 bytes: Stores a flag in a card record's bit 15 and returns 1; 0 for an out-of-range side or id.
- **`SzData_GetTreasureFlag`** `0x216ec0`, 180 bytes: Returns treasure flag `n` (0..21) from the bit array at `+0xfea0` as 0 or 1; 0 when the side or index is out of range.
- **`SzData_SetTreasureFlag`** `0x216f80`, 284 bytes: Sets or clears treasure flag `currentMap` (0..21) in the bit array at `+0xfea0` and returns 1; 0 when the side or index is out of range.
- **`SzData_SearchTreasure`** `0x2170a0`, 268 bytes: Searches the 22-entry table `aTreasureData` for an entry with the given id whose four-bit x and y coordinates both lie within `range` (exclusive) of (`col`, `row`) and returns that entry's halfword `+2`; 999 when none matches or the range (positive), id (0..21) or coordinates (0..6) are invalid.
- **`SzData_GetMapEditFlag`** `0x2171b0`, 120 bytes: Returns the map-edit bit (bit 5 of byte `+0xff9c`) as 0 or 1; 0 for an out-of-range side.
- **`SzData_SetMapEditFlag`** `0x217230`, 148 bytes: Stores a flag in the map-edit bit (bit 5 of byte `+0xff9c`) and returns 1; 0 for an out-of-range side.
- **`SzData_SetRankDirect`** `0x2172d0`, 252 bytes: Sets a card's rank (ids 0..682) to `rank` 0..12 and its experience `+0x4a` to that level's threshold in `gSzData_awExpTable`, returning the rank; -1 when the side, level or id is out of range.
