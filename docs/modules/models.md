# SzModel: models

119 functions, 47,544 bytes, all byte-matching. Names are the Japanese build's symbols where it has one ([topics/jp-build-symbols.md](../topics/jp-build-symbols.md)); `func_<address>` where it has none. Descriptions are readings of the C; field and parameter meanings are interpretations unless [GAME_DATA.md](../GAME_DATA.md) records evidence. The module's place in the program: [ARCHITECTURE.md](../ARCHITECTURE.md).

- **`SzModel_Init`** `0x1e7a60`, 180 bytes: Clears the 84 model table words (gSzModel_ahModel), sets the signed 27-bit model field at `+0x68` of each of the 32 112-byte motion-blur entries at `0x31ad00` to -1, clears the blur mode word, and sets the packing flag when `0x197548` returns non-zero for either of the strings at `0x2cf9d0` or `0x2cf9d5`. Returns 1.
- **`SzModel_Create`** `0x1e7b20`, 476 bytes: Allocates a model object for `modelId` (0..83) with SzMem_Alloc(0x210), stores it in the model table, clears it with RhMem_FillMemory4 and sets its starting values: scale 1.0 in all four components at `+0x30`, intensity 0.8/0.8/1.0 at `+0x120`, colour 0x80 in all four bytes at `+0x12c`, a zero filter quad at `+0x130`, -1 at `+0x1e1`, `+0x1ec`, `+0x1f2` and `+0x1f4`, the two-bit fields at `+0x1f7` and `+0x1f8` to 1, and the `+0x20c` flag bits to 1,1,0,0,0,0,1,1; then calls lSzModel_Clean and returns 1. Returns 0 for a bad index or a failed allocation.
- **`lSzModel_Clean`** `0x1e7d00`, 224 bytes: Resets the animation state of a model: the two slot vectors at `+0x198` to (1, 1, 1) and (1, 1, 0), the current and previous animation levels to 0 and -1, the stone flag and ratio, the maximum OT value, the interpolation count (6), frame and delay bytes and bit 5 of `+0x20c`; clears the reference IDs with SzModel_SetRefID(modelId, -1, 1) and stores 32767 at `+0x1f0`. Returns 1, or 0 for a bad index or empty slot.
- **`SzModel_Destroy`** `0x1e7de0`, 140 bytes: Frees a model's data with lSzModel_FreeModel and, when that succeeds, releases the object with SzMem_Free and clears its table slot; returns 1, or 0 for a bad index, an empty slot or a refused free.
- **`SzModel_Preset`** `0x1e7e70`, 248 bytes: Prepares a model for loading: waits with SzFile_DoRequestS while its loading bit (`+0x20c` bit 3) is set, frees its data, marks it not standing by (`+0x1f2` = -1), stores `modelType` at `+0x1f3` when non-negative and `modelNumber` at `+0x1f4`, and sets the ready bit (bit 2). Returns 1, or 0 for a bad index or empty slot.
- **`SzModel_LoadMerge`** `0x1e7f70`, 1372 bytes: Loads the shared model pack of type `modelType` (0..6, else 0). The nine model groups (class 0x292c10, count 0x292c40, first object 0x292c70, copied to the stack; group 7 gets nine objects for type 4) are selected by the type's mask in aShareData (0x292ba0); groups 0..6 take their wanted model numbers from the per-arg1 tables 0x2cebbc (10 bytes a row), 0x2cebc6, 0x2cebc8 (24), 0x2cecb8 (80, groups 3..5) and 0x2cee48 (20). The file entry is arg1 plus the type's first entry; its offset and length come from anOfs_MODEL and the next entry; the name is built with func_0019b648 from SzFile_GetEnv(0x2cf9f0). Text items are released (0/0 and 1/-1 when SzText_GetItem(0, 0) exists, unless type 4; 0/5, 0/6, 7/-1, 8/-1 unless type 3). Unless arg2 is set, the pack is requested only when a selected object is standing by or a wanted number below gSzModel_awIgnore[class] differs from SzModel_GetModelNo. Then every selected object is preset to 999 (class 4 also deletes units 1..10 of both sides), the type's own objects are preset to their wanted numbers, SzFile_ReadRequestParam(type, 0, name, address, length, offset, length, lSzModel_LoadMergeCB, entry) is called (0 on refusal) and each own object gets bit 2 of +0x20c cleared and bit 3 set.
- **`lSzModel_LoadMergeCB`** `0x1e84d0`, 688 bytes: Read callback of SzModel_LoadMerge. Copies the four 39-entry tables at 0x292ca0 (first slot), 0x292d40 (count), 0x292de0 (rebind limit) and 0x292e80 (offset lists) and, for each non-null model 0x31abb0[first + j] of group `req->user`, clears its loading bit (bit 3 of `+0x20c`). When the read completed, the model number at `+0x1f4` is below 0x2cf910[type at `+0x1f3`], j is below the rebind limit and the word at `data + offsets[j]` is 0x304852, it also clears bit 0 and binds the model in place with lSzModel_Clean and lSzModel_BindModelByAddr(slot, data + offsets[j]).
- **`SzModel_Load`** `0x1e8780`, 1132 bytes: Loads model file `modelNo` of class `modelType` into object 0..83; waits while the object is busy, stores class and number, refuses numbers outside the class count; with packing on and the pack label present, classes 4..6 read one megabyte per monster from the pack (id from SzDuel_Xax2New, 737 maps to 671, ids of 683 or more refused: 683 is the monster count and bounds the pack offset id << 20) and class 1 reads an anOfs_MODEL entry; everything else loads the named file. Returns 1 when requested.
- **`lSzModel_LoadCB`** `0x1e8bf0`, 664 bytes: Finishes a model load for object `index & 0x3ff` (below 84, with bound file data): clears the loading bit, records the index, for kinds 4-6 copies the id and takes its 14-bit look value from the two halfword tables, resolves the root node (file + header offset), measures the node tree depth with lSzModel_GetGNode, copies the node position (w = 1) and radius, clamps the scale 40/radius to 0.3..1, and replaces motion selectors that name an absent motion. For kinds 4-6 it then reads two environment labels, clears file flag 0x400 and calls SzEffect_LoadModule(1, id, 0).
- **`lSzModel_LoadCameraCB`** `0x1e8e90`, 264 bytes: Read callback of a model camera file. Picks the object by the low seven bits of the request word `+0x1c` (bit 7 selects the second camera word); without an object nothing happens. When the object has no file data (`+0x138`) the loaded data is freed and the read treated as failed. On failure the selected word (`+0x16c` or `+0x170`) is cleared; otherwise the data address is stored there and bit 0x80000 (first) or 0x100000 (second) of the file flag word is cleared; the first also stores its halfword `+12` minus one at `+0x204` and `+0x202`.
- **`SzModel_BindTextureFile`** `0x1e8fa0`, 272 bytes: Binds the textures embedded in a model file: returns 0 for a bad index or empty slot and 1 without changes when the object has no file data (`+0x138`) or the descriptor (`+0x13c`) word `+0x2c` is 0. Otherwise walks the table at `base + desc[+0x28]` (count, then 16-byte entries): each entry with a non-zero texture offset is rebased to an address and passed to RhText_BindAddress, its third word is rebased when non-zero and its fourth cleared. Returns 1.
- **`SzModel_LoadTextureFile`** `0x1e90b0`, 460 bytes: For a loaded object with a texture table, builds `<env>/<kind dir>/%s` once, then per table entry submits `<name>.rh2` (callback lSzModel_LoadTextureFileCB) and `<name>.anm` (lSzModel_LoadTexAnimFileCB) through SzFile_ReadRequest with a word holding the low 26 bits of the entry list address and the entry index in the top six bits, clearing fields a, c and d of the entry first. Returns 0 for a bad index or empty slot, else 1.
- **`lSzModel_LoadTextureFileCB`** `0x1e9280`, 64 bytes: Read callback of the texture file requests. The request user word (+0x1c) holds the entry list address in its low 26 bits and the entry index in its top six; when the read completed (second argument non-zero) the loaded data (+0x14) is stored as the texture of that 16-byte entry and passed to RhText_BindAddress; otherwise nothing happens.
- **`lSzModel_LoadTexAnimFileCB`** `0x1e92c0`, 128 bytes: Read callback of the texture animation file requests, entry chosen as in the texture callback. When the read completed the loaded data is stored in the entry word at +8; if it is not null the text is ended with a zero byte at size - 1 (31-bit size at +8 of the request), the word is replaced by lSzModel_TexAnimConv(entry texture, text) and the text is freed with SzMem_Free.
- **`lSzModel_TexAnimConv`** `0x1e9340`, 3496 bytes: Parses a texture-animation description text (arg1, tokenised in place into lines; lines starting with # are skipped) for the texture file arg0 into a newly allocated table of 24-byte entries (SzMem_Alloc(count * 24)): each line's keyword (one of seven at 0x292f40) selects how its fields are scanned (name, flags, place, size and frame values, clamped to their ranges, positions checked against the texture's width and height at +0x44 / +0x46 of the header at arg0 + 0x10), with a message for a malformed line. With no line, or no memory, the text's first entry is marked last and empty and the result is null. Switch table at 0x2cf930 (28 bytes).
- **`SzModel_LoadEffectTextureFile`** `0x1ea0f0`, 372 bytes: Requests a model's effect textures. Returns 0 for a bad index or empty slot, and 1 without work when the object has no file data (`+0x138`). Otherwise it reads the "DBDIR" environment label, clears `+0x140` and the eight words at `+0x144`, and submits nine reads through SzFile_ReadRequest with callback lSzModel_LoadEffectTextureFileCB and the address of the word to fill: `<dir>/<kind>/TEX/M<number>.rh2` for `+0x140`, then eight names from "%s/%s/TEX/B%%03d_%%d.rh2" for `+0x144`, each formatted with the model number twice (the loop counter is passed but not used by the format). Returns 1.
- **`lSzModel_LoadEffectTextureFileCB`** `0x1ea270`, 44 bytes: Read callback of SzModel_LoadEffectTextureFile: when the read completed, stores the loaded data address through the word pointer held in the request's user word (`+0x1c`) and passes it to RhText_BindAddress.
- **`SzModel_LoadTexture_Pipe`** `0x1ea2a0`, 360 bytes: Clears *size_out when given. Without a model, or with a zero word at model +0x3c, returns the cursor unchanged. Otherwise takes a buffer position from RhBase_GetUserGsAddress, advances it by SzText_InitClutManage(position, 2) and, for every record with a non-zero first word, emits SzText_Load_Pipe (which reports a length), then, when the record's word +8 is set and SzModel_GetPauseFlag(modelId) and SzModel_GetStoneFlag(modelId) are both zero, emits SzModel_LoadTexAnim_Pipe and counts it in the record's word +0xc; the position advances by the reported length. Stores the bytes used in *size_out and ends with RhText_SetTextureFlush.
- **`SzModel_LoadTexAnim_Pipe`** `0x1ea410`, 1608 bytes: Walks the 24-byte texture-animation entries of the record until the one marked last; for each entry whose mask has the bit of SzModel_GetAnim(index) it advances the cell by the entry type (loop, swing, timed gate, frame window; a seven-entry switch), using the animation frame or the entry counter and stepping only when the pause flag is clear, and appends a 12-doubleword GS transfer (BITBLTBUF from position, width/64 and pixel format; TRXPOS from the cell; TRXREG; TRXDIR 2); when any was written the first tag words get the quadword count. Returns the advanced cursor.
- **`SzModel_Act`** `0x1eaa60`, 10752 bytes: The per-frame update of model `modelId` (0..0x53; 0 for an index out of range or an empty slot, else 1). When the model's viewer page (+0x1f2) is the debug viewer's active model (SzDebug_GetActiveModel), the pad (SzPad_Check) drives, by viewer page (SzDebug_GetActiveMenu), animation choice, speed, interpolation and stepping (page 1), camera, effect, text and motion-blur requests (page 2 and others), scale, intensity, colour and filter edits; in mode 5 with motion blur on it requests the blur every other frame, and unless the debug display is hidden it computes the digit position of the edited value.
- **`lSzModel_EffectCB`** `0x1ed460`, 60 bytes: Effect completion callback installed by SzModel_BattleSeq: for a `modelId` in 0-83 whose model slot is not empty, sets the object's effect handle (`+0x1ec`) to -1.
- **`SzModel_Motion`** `0x1ed4a0`, 1432 bytes: Per-frame animation step of model `modelId`. Rejects a bad index, a null entry, a negative byte at +0x1f2, a null link at +0x138, bit 3 of +0x20c set or bit 1 clear (returns 0); returns 1 untouched when the pause flag (bit 0 of +0x20d) is set. Otherwise advances the blend slot frame (+0x1a8) and the current slot frame (+0x19c) by speed times SzGame_GetFrameSpeed in the direction of the signed 2-bit field at +0x1f7 with wrap/clamp against the slot length (+0x1c0), advances the blend ratio (+0x1a0 = +0x1fc / +0x1fb), stops slots 3 and 4 at their last frame, holds slot 6 at frame 10 for 15 calls, switches to the queued slot (+0x1e3) on wrap, and counts +0x1ff up to 32 or down to 0 by bit 4 of +0x20c.
- **`SzModel_ReqSE`** `0x1eda40`, 612 bytes: Plays the sound cues of a model's current motion. Returns 0 unless channel is 2 or 3 and the object passes: `modelId` 0..83, non-null, `+0x1f2` not negative, `+0x138` set, bit 3 of `+0x20c` clear, bit 1 set, bit 0 of `+0x20d` clear, word `+0x1ec` not negative or the two-bit field of `+0x1f7` equal to 1, and a non-null cue list at `+0x174`. Then now/kind are float `+0x19c` and byte `+0x1e0`, or `SzEffect_GetCount(+0x1ec)` and 2 when `+0x1ec` is not negative; for up to 64 four-byte cues, stopping at kind 15, each cue of that kind with `now - SzGame_GetFrameSpeed() <= time < now` has its code passed to `SzSound_PlaySE(channel, code)`; returns 1.
- **`SzModel_ReqMotionBlur`** `0x1edcb0`, 612 bytes: Starts a motion blur for a model: returns 0 unless object `modelId` exists with a `+0x1f3` kind of 4 or 5 and one of entries 1-31 of the 112-byte blur table at 0x31ad00 is free (negative model field). - **`SzModel_CancelMotionBlur`** `0x1edf20`, 104 bytes: Frees the motion-blur entries 1-31 in use, either all of them (negative argument) or those of the given model, by setting their model field to -1.
