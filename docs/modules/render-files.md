# Rh: files, models, geometry

163 functions, 46,676 bytes, all byte-matching. Names are the Japanese build's symbols where it has one ([topics/jp-build-symbols.md](../topics/jp-build-symbols.md)); `func_<address>` where it has none. Descriptions are readings of the C; field and parameter meanings are interpretations unless [GAME_DATA.md](../GAME_DATA.md) records evidence. The module's place in the program: [ARCHITECTURE.md](../ARCHITECTURE.md). Library routines in the text (sce*, C library) carry the Japanese build's names; some of those are placed only by position and the two builds' SDK versions differ, so treat them as likely, not certain.

- **`RhFile_Init`** `0x1fffc0`, 424 bytes: Initialises the IOP side: resets and waits on the SIF and CD services through library calls, loads each IOP module of the null-terminated list at `0x2cfce0` with `RhFile_LoadIopModuleWrapper` (returning 0 on the first failure), then, when an environment string at `0x2d0638` is set, looks up each of the 97 entries of `mapFile` on the disc, storing its first sector and sector count or replacing a missing entry's name with the text at `0x2d066f`. Finally sets up the CD stream buffer and installs `lRhFile_CdCallback`; returns 1.
- **`lRhFile_CdCallback`** `0x200170`, 148 bytes: CD completion callback: for reason 1 with the pending bit set, ends the cached request with `lSzFile_TermRequest(result, 1)` when `0x191ef8` reports 0, else clears the bit. Ends with `sync` and `ei` (one inline-assembly line, as it has no C spelling).
- **`RhFile_Term`** `0x200210`, 8 bytes: Returns 1.
- **`RhFile_LoadIopModuleWrapper`** `0x200220`, 16 bytes: Calls `RhFile_LoadIopModuleWrapperEx(name, 0, 0, argument)`.
- **`RhFile_LoadIopModuleWrapperEx`** `0x200230`, 196 bytes: Uppercases `name` in place, builds `cdrom0:\IOP\<NAME>;1` in the shared buffer at `0x31c2f0`, and retries loading the module with `sceSifLoadModule(path, argument_size, arguments)` (`0x183538`) until it succeeds (no retry limit); returns 1. Both arms of the `flag` test do the same thing.
- **`lRhFile_StrUpper`** `0x200300`, 68 bytes: Converts the lower-case letters `a`–`z` of a zero-terminated text to upper case in place.
- **`RhFile_VSyncProcess`** `0x200350`, 8 bytes: Does nothing.

- **`RhFile_ReadAndBlock`** `0x2003e0`, 224 bytes: Returns 0 for a negative first argument (otherwise unused); else queues a read of the path saved by `RhFile_OpenFile` through `SzFile_ReadRequestParam` with `lSzFile_ReadCB`, services requests until none is pending and returns 1 if the read completed, else 0.

- **`lRhFile_ReadCB`** `0x200680`, 56 bytes: Read callback installed by `RhFile_ReadAndCallbackByFileName`: calls the saved function, if any, with the request record's word at +0x1c.
- **`RhFile_ExistFile`** `0x2006c0`, 268 bytes: Returns 0 for a null name.
