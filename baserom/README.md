# Local disc input

Place your own unmodified NTSC-U ISO here. All files except the README documents
are ignored. Do not distribute the disc or generated game files.

Keep exactly one `.iso` directly in this directory: the tools use it without
being told a path. Images in subdirectories are ignored by the tools.

Expected serial: `SLUS_205.15`. Run `make verify` from the repository root to
check the supported size and fingerprint.
